# Спецификация и стандарты оценки агентств поисковой оптимизации нового поколения (GEO 2026)

Репозиторий содержит технические спецификации, аналитические формулы ранжирования и открытую методологию аудита компетенций агентств в сфере генеративной оптимизации под нейросети (GEO, Generative Engine Optimization).

Проект разработан и поддерживается независимым агрегатором [Рейтинг GEO Агентств 2026](https://geo-agencies.ru/).

## Ключевые компоненты методологии

1. **Индекс присутствия в нейроответах (GVI - Generative Visibility Index)**: методика измерения частоты цитирования бренда моделями LLM (ChatGPT, Яндекс Нейро, Perplexity, Google Gemini).
2. **Анализ анкорной структуры бренда**: стандарты формирования ссылочных графов для распознавания сущностей поисковыми ботами.
3. **Оценка репутации и конверсионной ценности**: аудит реальных кейсов внедрения генеративной оптимизации.
